# Java Expense Tracker

## Overview
A command-line Java application that allows users to track their income and expenses. 
Users can add transactions, categorize them, view their current balance, and see spending totals by category. 
Data is persisted locally using a CSV file.

## Purpose
This project was created as Module #3 for CSE 310 to demonstrate mastery of core Java concepts, 
including object-oriented programming (inheritance, interfaces, abstract classes), 
the Java Collection Framework (ArrayList, HashMap), and File I/O.
